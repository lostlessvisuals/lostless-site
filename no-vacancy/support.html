NO VACANCY

Support

No Vacancy is an on-device iPhone focus blocker built around Apple's Screen Time tools. This page covers the expected workflow, common sticking points, and basic troubleshooting for the current release.

Core workflow

  • Create a preset with the apps, websites, or categories you want blocked.
  • Add a schedule, a daily limit, or start a focus session from Home.
  • Grant Screen Time access when prompted so blocking can actually apply.
  • Use Reload / Re-apply Shields on the Blocks screen if the system ever looks out of sync.

What is expected

  • All presets, logs, and reflections stay on the device.
  • No account is required.
  • Notifications are optional and blocking should still work without them.
  • Hard and Deep add more friction before you can end a session early.

Troubleshooting

  • If nothing blocks, reopen the app and confirm Screen Time access is still enabled.
  • If a blocked app slips through, go to Blocks and tap Reload / Re-apply Shields.
  • If something stays blocked longer than expected, reopen the app so it can recheck the active rule state.
  • If a daily limit or schedule looks wrong, edit the rule and confirm the selected preset and days are correct.

Purchases

No Vacancy Pro is a one-time unlock handled through Apple's in-app purchase flow. Free includes one preset plus one schedule or limit. Pro unlocks unlimited rules, stronger friction modes, and weekly review features.
