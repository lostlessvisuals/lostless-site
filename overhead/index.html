O V E R H E A D

Build with an agent.
Direct in real time.

I built Overhead to make generative visuals and direct them in real time. In this demo, I perform four visuals to one track and choose when and how to move between them.

Working with the track

I use the agent to try variations, then play them against the track to decide what should react. In Signal Archive, the opening piece, the kick makes the grid pulse and the snare briefly cuts across the image.

Bringing in the next visual

I keep finished pieces in a library so I can bring different combinations together for each set. In the demo, I cue the next visual while the current one is still running. Each change uses a two-second Difference blend. In the last one, the shape from Obscura stays visible as the blue and gold ribbons of False Gravity appear.
