FIRECHECK LITE

Support

FireCheck Lite is an offline iPhone logbook for monthly fire extinguisher inspections. This page covers the expected workflow, common questions, and basic troubleshooting for the release build.

Core workflow

  • Create a property and add each extinguisher by tag ID and location.
  • Start a monthly check from the property screen.
  • Complete the six-point inspection, enter inspector initials, and save the check.
  • Generate PDF or CSV exports from the Reports screen when you need to share records.

What is expected

  • Inspection records stay local to the iPhone.
  • No account creation is required.
  • QR and NFC support are optional convenience paths, not required for basic use.
  • The free tier supports one property with up to three extinguishers.

Troubleshooting

  • If scanning does not work, use manual tag entry instead.
  • If you cannot add another extinguisher or property, check whether you are at the free-tier limit.
  • If an export does not appear immediately, reopen Reports and generate it again from the selected export card.
  • If camera or NFC access is denied, the app should still work for manual inspections and exports.
